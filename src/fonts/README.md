# Caratteri

Copie dei caratteri di Google Fonts (repository google/fonts), ridotte a
latino, latino esteso e cirillico e convertite in woff2. Stanno nel progetto
così la build non dipende da Google Fonts. Licenza: SIL Open Font License 1.1.

Geist, Geist Mono, Inter (opsz 14), Playfair Display, Cinzel,
Cormorant Garamond (normale e corsivo), IBM Plex Mono SemiBold.
